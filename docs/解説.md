# キャンディ・ハイブリッドロケットの計算設計（学部1年向け解説）

対象論文：Wada et al., "Development of a Candy Hybrid Rocket Motor for Undergraduate Space Education",
Trans. JSASS Aerospace Tech. Japan, Vol.16, No.6, pp.506-510 (2018)

計算コード：`calc/candy_motor.py`（実行すると `calc/results.json` と `calc/flight_and_OF.png` ができます）

> **この資料の約束ごと**
> **[論文]** = 論文に書いてある数値（表・図の番号つき）
> **[仮定]** = 論文に無く、私が置いた値（本当に正しいかは要確認）
> **[計算]** = 上の2種類から計算で出した値
> 熱化学計算ソフト（NASA CEA）はこの環境に入れられなかったので、**CEAの出力は一切作っていません**。図2の値は「図から読み取った」と明記します。

---

## 0. そもそも何をしたの？

論文は「飴（ソフトキャンディ）を燃料に、亜酸化窒素（N₂O）を酸化剤にしたロケットモーター」を作り、飛ばした報告です。
ここでは次の**一周**を自分で計算しました。

```
論文の実験データ → ①データの整合性チェック → ②モーターの寸法を決める
                 → ③飛行高度を計算 → ④論文の結果と照らし合わせる
```

## 1. 基本の用語（先に覚えておくと楽）

| 用語 | ひとことで | 式 |
|---|---|---|
| 推力 F | ロケットを押す力 [N] | |
| 全力積 It | 推力×時間。「押した総量」[N·s] | It = F × 燃焼時間 |
| 比推力 Isp | 推進剤の「燃費」。大きいほど少ない量で長く押せる [s] | Isp = It ÷ (推進剤の質量 × g₀) |
| O/F | 混ぜ方の比率。酸化剤の質量 ÷ 燃料の質量 | |
| 燃焼圧 Pc | 燃焼室の中の圧力 | |
| スロート | ノズルの一番細い所 | |
| ハイブリッド | 燃料は固体、酸化剤は液体（別々に貯める）方式 | |

g₀ = 9.80665 m/s²（重力加速度の標準値）。

## 3. ステップ① データのつじつまを確認する

### (a) 推力×時間 ＝ 全力積？
351.8 N × 2.62 s ＝ **921.7 N·s**。論文の値と一致します。 ✔

### (b) 推進剤は全部で何kg？
定義 Isp = It ÷ (m × g₀) を変形して

m ＝ It ÷ (Isp × g₀) ＝ 921.7 ÷ (168.2 × 9.80665) ＝ **0.559 kg**

（前提：論文のIspがこの定義で出されていること。論文には明記がないので **[仮定]**）

### (c) 酸化剤は何kg？ O/Fはいくつ？
酸化剤 ＝ 0.559 − 0.064 ＝ **0.495 kg**、
O/F ＝ 0.495 ÷ 0.064 ＝ **7.7**

**ここが最初の発見です。** 図2（理論計算）で飴の主成分のショ糖が描かれている O/F は、図から読み取ると **約1.5〜3** の範囲です。
実験から逆算した O/F＝7.7 はその範囲よりずっと「酸化剤が多すぎ」です（燃料64gに対し酸化剤が多い）。

### (d) チームAのロケットで検算
Table 6：湿潤質量 4.240 kg − 乾燥質量 3.670 kg ＝ **0.570 kg**。
(b) の 0.559 kg とほぼ一致（差 約2%、燃え残りや計量誤差の範囲と考えられる）。 ✔
→ 「モーターが約0.56 kgの推進剤を使う」という読みは、論文の2か所から裏が取れました。

### (e) 論文の中の食い違い（そのまま報告）
酸化剤質量流束 G_ox（単位面積・単位時間あたりの酸化剤流量）が

* Table 2：**70** kg/m²s
* 2.3節の本文：**300** kg/m²s

と、論文内で2通り出てきます。私の計算では ṁ_ox ＝ 0.495 ÷ 2.62 ＝ 0.189 kg/s なので

* 内径50 mm（Table 1）の流路で割ると **96** kg/m²s
* 直径65 mmで割ると 57 kg/m²s（Fig.1bから読み取った寸法）

どちらにも一致しません。**どれが正しいかは論文の情報だけでは決められません**ので、設計では自分の計算値（約96）を使います。

## 4. ステップ② モーターの寸法を決める

### 流量（1秒あたりの質量）
* 合計：ṁ ＝ 0.559 ÷ 2.62 ＝ **0.213 kg/s**
* 酸化剤：**0.189 kg/s**、燃料：**0.0244 kg/s**

### ノズルのスロート面積
推力の式 F ＝ C_F × Pc × A_t から

A_t ＝ F ÷ (C_F × Pc)

C_F（推力係数）は、γ＝1.2 **[仮定]** と、海面で出口圧＝大気圧になる膨張を仮定した**理想値**で **1.445**。すると

A_t ＝ 351.8 ÷ (1.445 × 2.5×10⁶) ＝ 9.7×10⁻⁵ m² ＝ **97 mm²**
スロート直径 ≈ **11.1 mm**、出口直径 ≈ 36.8 mm（面積比 ≈ 10.9）

* 本物のノズルでは損失があるので C_F は理想より小さく、スロートはやや大きくなります。
* 特性排気速度 c* ＝ Pc × A_t ÷ ṁ ＝ **約1140 m/s**（この寸法から逆算した値）。
* ⚠ 注意：A_t を推力から決めたので、「ここから出した Isp が 168 s に戻る」のは**当たり前**で、検証にはなっていません。

### 酸化剤（N₂O）タンク
酸化剤0.495 kg に20%の余裕 → 0.594 kg。液体密度786 kg/m³（**[仮定]**）で
体積 ≈ 0.76 L、さらに空間（アレージ）20% → **約0.9 L**。

## 5. ステップ③ 飛行高度を計算する

ロケットの質量が燃料の消費で減ること、重力、空気抵抗を入れて、1秒を1000等分した時間刻みで運動方程式

(質量 m) × (加速度 a) ＝ 推力 − 抗力 − 重力

を解きました。推力は平均値で一定と**仮定**（実際の曲線 Fig.5 は概ね平らです）。
空気密度は標準大気の式、抗力係数 Cd は論文に無いので 0.3 / 0.5 / 0.7 を試しました（**[仮定]**）。

### まず「空気抵抗ゼロ」の上限を調べる
Table 5 の「乾燥質量10 kg」に推進剤0.559 kg を足して計算すると：

| 場合 | 頂点高度 |
|---|---|
| 抵抗なし | **292 m** |
| Cd=0.3 / 0.5 / 0.7 | 272 / 261 / 251 m |
| 論文の計算値 / 実測 | 313 m / 319 m |

**抵抗ゼロでも313 mに届きません。** どんなCdでも合いません。
つまり、「10 kg＝空の機体」と読むと、論文の計算値は再現できません。

もし「10 kgは発射時の全質量（推進剤込み）」と読むと（質量 9.44 kg + 推進剤）、抵抗なし 333 m、Cd≈0.22 で313 mになり、現実的な範囲に入ります。
→ **論文の質量の定義が明確でないことが原因の可能性が高い**（これは私の推測で、論文からは確認できません）。

頂点に達する時刻は、計算で約9 s。Fig.7 の読み取り（約9 s）と整合します。

### 追加の検算：チームA（Table 6）
乾燥 3.67 kg、推進剤 0.57 kg、直径 89 mm：抵抗なし 2574 m。Cd=0.56 で論文計算値 1289 m を再現（妥当な範囲）。 ✔

### 追加の検算：チームB（Table 7）
湿潤−乾燥 ＝ 4.652−4.322 ＝ 0.330 kg しかありません（チームAの6割弱）。
この推進剤量・同じIsp・同じ燃焼時間だと、**抵抗なしでも約590 m**にしか届かず、論文の計算値1187 mは再現できません。
1187 mに届く（抵抗なし）ためには推進剤が約0.46 kg必要です。
→ 湿潤質量・乾燥質量の定義が違う（例えば乾燥質量に燃え残りや別部品が含まれる等）可能性があります。**原因は確定できません**。

## 6. ステップ④ まとめ：数字がぴったり合わない理由

1. **O/Fが理論の範囲より大きく外れている**（7.7 vs 1.5〜3）。
   燃料が64 gと少なく、酸化剤が余っている状態で、これが「実測 Isp 168 s が理論（図2で約200〜220 s）より低い」ことの有力な説明候補です。
   ただし、これは「そうかもしれない」という仮説で、Ispの定義や燃え残りなどの影響は論文からは分離できません。
2. **質量の定義があいまい**（Table 5〜7）で、高度の計算値が再現できない場合がある。
3. 空気抵抗係数、γ、N₂O密度は論文に無く、私の仮定。

## 7. 一年生のための要点

* ロケットの性能は **「押す力 × 押す時間 ＝ 全力積」** と **「推進剤1kgでどれだけ押せるか＝比推力」** で決まる。
* 論文の数値は**まず自分で検算する**。推力×時間＝全力積（OK）、推進剤質量が2か所で一致（OK）、でも質量流束は70と300でバラバラ（要注意）。
* 理論と実験がずれたら、**混合比 O/F**、**質量の定義**、**仮定した値**の順に疑う。
* 「合わせるためにパラメータをいじる」のではなく、**合わない事実をそのまま報告する**のが誠実な設計計算。

## 付録：限界

* CEAが使えず、図2（O/Fごとの Isp）は図から目で読み取った概数です。
* 推力は一定として計算しており、実際の推力曲線（Fig.5）の形は反映していません。
* 風・発射レール・パラシュート展開は考慮していません。
